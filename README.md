# ⏱️ 학원 업무 시간 추적기

학원(교육기관)에서 업무 효율을 높이기 위한 시간 관리 도구입니다.

## 🎯 주요 기능

- ⏰ **실시간 타이머**: 각 업무를 시작하고 종료하며 정확한 시간 추적
- 📊 **카테고리별 분류**: 6가지 업무 카테고리로 체계적인 시간 관리
  - 수업/강의
  - 학생 상담
  - 행정 업무
  - 자료 준비
  - 회의
  - 기타
- 📈 **주간 통계**: 지난 7일간의 업무 시간을 카테고리별로 요약
- 💾 **자동 저장**: localStorage를 통한 데이터 자동 저장
- 📱 **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 지원
- 🎨 **직관적인 UI**: 깔끔하고 사용하기 쉬운 인터페이스

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

개발 서버가 시작되면 브라우저에서 `http://localhost:5173`로 접속하세요.

### 프로덕션 빌드

```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

### 프리뷰

```bash
npm run preview
```

## 📦 사용 기술 스택

- **React 19** - UI 라이브러리
- **TypeScript** - 타입 안정성
- **Vite** - 빠른 빌드 도구
- **CSS3** - 모던 스타일링

## 🎮 사용 방법

1. **카테고리 선택**: 시작하고 싶은 업무 카테고리를 선택합니다
2. **타이머 시작**: "시작하기" 버튼을 클릭하여 타이머를 시작합니다
3. **업무 진행**: 타이머가 실행되는 동안 업무를 진행합니다
4. **타이머 종료**: "정지하기" 버튼을 클릭하여 타이머를 종료합니다
5. **통계 확인**: 이번 주 활동 요약에서 전체 업무 시간과 카테고리별 분석을 확인합니다

## 📊 데이터 관리

- 모든 시간 기록은 브라우저의 localStorage에 자동으로 저장됩니다
- 데이터는 브라우저가 닫혀도 유지됩니다
- "데이터 초기화" 버튼으로 모든 기록을 삭제할 수 있습니다
